1. Introdução à Genética

Genética é o ramo da biologia que estuda a herança biológica — como as características são transmitidas dos pais para os filhos.

Conceitos Fundamentais

ConceitoDefinição
GeneSegmento de DNA que codifica uma proteína
AleloFormas diferentes de um gene
GenótipoConstituição genética de um indivíduo
FenótipoManifestação externa do genótipo
CromossomoEstrutura de DNA associado a proteínas

Princípio Central da Biologia Molecular

O DNA é transcrito em RNA, que é traduzido em proteína. As proteínas são responsáveis pelas características do organismo.

3. Estrutura do DNA

DNA = Ácido Desoxirribonucleico — a molécula que armazena as informações genéticas.

Dupla Hélice

    Fita 1                    Fita 2
      │                         │
  ────A═══════════════════════T────
  ────T═══════════════════════A────
  ────G═══════════════════════C────
  ────C═══════════════════════G────
      │                         │
   backbone               backbone
  (desoxirribose + fosfato)

Nucleotídeos

Cada nucleotídeo é composto por:

  • Fosfato (PO₄³⁻)
  • Desoxirribose (açúcar)
  • Base Nitrogenada (A, T, C ou G)

Bases Nitrogenadas

BaseTipoPareia com
Adenina (A)PurinaTimina (T)
Timina (T)PirimidinaAdenina (A)
Guanina (G)PurinaCitosina (C)
Citosina (C)PirimidinaGuanina (G)

Regra de Chargaff

A = T e G = C (bases complementares)

4. Estrutura do RNA

RNA = Ácido Ribonucleico — transporta a informação do DNA para os ribossomos.

DNA vs RNA

CaracterísticaDNARNA
AçúcarDesoxirriboseRibose
BasesA, T, G, CA, U, G, C
Fitas2 (dupla hélice)1 (única fita)
LocalizaçãoNúcleoNúcleo + Citoplasma
FunçãoArmazenar infoTransportar info

Tipos de RNA

mRNA

RNA Mensageiro — transporta a informação do DNA para o ribossomo

tRNA

RNA Transportador — transporta aminoácidos para o ribossomo

rRNA

RNA Ribossomal — componente dos ribossomos

Diferença chave

No RNA, a Uracila (U) substitui a Timina (T).

6. Transcrição (DNA → RNA)

Processo em que a informação de um gene do DNA é copiada para um RNA mensageiro.

Localização: Núcleo celular

DNA (fita molde):  3'─TAC─GCA─AAT─CGG─5'
                          ↓   ↓   ↓   ↓
mRNA formado:      5'─AUG─CGU─UUA─GCC─3'

Passos da Transcrição

1

Iniciação

A RNA Polimerase se liga ao promotor e a dupla hélice se abre.

2

Elongação

A RNA Polimerase percorre a fita (3'→5') montando o mRNA (5'→3').

DNA A → RNA U | DNA T → RNA A | DNA G → RNA C | DNA C → RNA G

3

Terminação

A RNA Polimerase encontra um sinal de terminação e o mRNA é liberado.

Processamento do mRNA

Pré-mRNA:  5'─exon─intron─exon─intron─exon─3'
                    ↓ Splicing
mRNA:      5'─exon──────exon──────exon─3'

Íntrons são removidos, exons ficam no mRNA final.

7. Tradução (RNA → Proteína)

Processo em que o mRNA é interpretado pelos ribossomos para produzir uma proteína.

Localização: Ribossomos (citoplasma)

Componentes da Tradução

ComponenteFunção
mRNAFornece a mensagem (códons)
tRNATransporta aminoácidos
RibossomoMáquina de síntese proteica
AminoácidosBlocos de construção das proteínas

Ribossomo

     ┌───────────────────┐
     │   Subunidade      │
     │   Grande (60S)    │
     │  ┌─────────────┐  │
     │  │  Sítio P    │  │  ← Peptidil-tRNA
     │  ├─────────────┤  │
     │  │  Sítio A    │  │  ← Aminoacil-tRNA
     │  ├─────────────┤  │
     │  │  Sítio E    │  │  ← Saída
     │  └─────────────┘  │
     │   Subunidade      │
     │   Pequena (40S)   │
     └───────────────────┘

Passos da Tradução

1

Iniciação

O tRNA iniciador (Met) se liga ao códon AUG.

2

Elongação

Cada códon é lido, o tRNA complementar se liga, aminoácido é adicionado.

3

Terminação

O ribossomo encontra um código de parada (UAA, UAG ou UGA).

mRNA:  5'─AUG─GCU─UAC─AAA─UGA─3'
          │    │    │    │    │
         Met  Ala  Tyr  Lys  STOP
          │    │    │    │
          └────┴────┴────┘
              PROTEÍNA

8. O Código Genético

Códon = grupo de 3 nucleotídeos do mRNA. Existem 64 códons possíveis.

Propriedades do Código

Degenerado

Vários códons → mesmo aminoácido

Universal

Mesmo código em quase todos os seres vivos

Não sobreposto

Cada nucleotídio pertence a um só códon

Unívoco

Cada códon → apenas um aminoácido

9. Regulação Gênica

Nem todos os genes precisam estar ativos o tempo todo. Células diferentes expressam genes diferentes.

Níveis de Regulação

1

Transcriacional (mais importante)

DNA → mRNA (ativador/repressor)

2

Pós-transcricional

Processamento do mRNA (splicing alternativo)

3

Traducional

mRNA → proteína (acesso ao ribossomo)

4

Pós-traducional

Modificação da proteína (fosforilação, clivagem)

12. Exercícios

Exercício 1: Complementaridade

Se a fita molde do DNA é: 3'─TAC GCA AAT CGG 5'

a) Qual é a sequência do mRNA transcrito?

b) Quais aminoácidos são codificados?

Exercício 2: Tabela do Código Genético

Determine os aminoácidos para:

a) 5'─AUG UUU GAA 3'

b) 5'─UAC AAA GGU 3'

Exercício 3: Mutação

Sequência normal: 5'─AUG GCU UAC AAA UGA 3'

Após mutação (4º nucleotídeo G→A): 5'─AUG ACU UAC AAA UGA 3'

a) Quantos aminoácidos diferentes resultado?

Exercício 4: Verdadeiro ou Falso

  1. ( ) O RNA possui a base Timina.
  2. ( ) A tradução ocorre no núcleo.
  3. ( ) O códon AUG codifica metionina.
