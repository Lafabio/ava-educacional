## 1. Introdução à Genética

### O que é Genética?

Genética é o ramo da biologia que estuda a **herança biológica** — como as características são transmitidas dos pais para os filhos.

### Conceitos Fundamentais

| Conceito | Definição |
|----------|-----------|
| **Gene** | Segmento de DNA que codifica uma proteína |
| **Alelo** | Formas diferentes de um gene |
| **Genótipo** | Constituição genética de um indivíduo |
| **Fenótipo** | Manifestação externa do genótipo |
| **Cromossomo** | Estrutura de DNA associado a proteínas |
| **Hereditariedade** | Transmissão de características de geração em geração |

### A Relação DNA → RNA → Proteína

```
DNA (no núcleo) → RNA (no núcleo) → Proteína (no citoplasma)
     Transcrição              Tradução
```

> **Princípio Central da Biologia Molecular**: O DNA é transcrito em RNA, que é traduzido em proteína. As proteínas são responsáveis pelas características do organismo.

## 2. O Núcleo Celular

### Estrutura do Núcleo

O núcleo é o **centro de controle da célula**. É onde o DNA está armazenado.

```
┌─────────────────────────────────┐
│         NÚCLEO CELULAR          │
│  ┌───────────────────────────┐  │
│  │      Cromatina/DNA        │  │
│  │   (genes distribuídos)    │  │
│  │                           │  │
│  │      ┌─────────┐         │  │
│  │      │ Nucléolo│         │  │
│  │      └─────────┘         │  │
│  └───────────────────────────┘  │
│  Membrane nuclear (poros)       │
└─────────────────────────────────┘
```

### Componentes do Núcleo

| Estrutura | Função |
|-----------|--------|
| **Membrane nuclear** | Envolve e protege o DNA; possui poros para transporte |
| **Cromatina** | DNA + proteínas (histonas); forma relaxada do DNA |
| **Cromossomos** | DNA condensado (durante divisão celular) |
| **Nucléolo** | Produz os ribossomos (organela da síntese proteica) |
| **Matriz nuclear** | Suporte estrutural interno |

### Cromossomos

- **Humanos**: 46 cromossomos (23 pares)
  - 22 pares **autossômicos** (corpo)
  - 1 par **sexual** (XX ou XY)
- Cada par possui um cromossomo de cada progenitor

### Cromatina vs Cromossomo

```
Cromatina (interfase)          Cromossomo (divisão)
    ~~~~~~~~~~~~~~~~~~         ╳
    DNA relaxado               DNA condensado
```

## 3. Estrutura do DNA

### O que é DNA?

**DNA** = Ácido Desoxirribonucleico
É a molécula que armazena as **informações genéticas**.

### Dupla Hélice

O DNA possui a forma de uma **dupla hélice** (descoberta por Watson e Crick, 1953).

```
    Fita 1                    Fita 2
      │                         │
  ────A═══════════════════════T────
  ────T═══════════════════════A────
  ────G═══════════════════════C────
  ────C═══════════════════════G────
  ────A═══════════════════════T────
  ────T═══════════════════════A────
      │                         │
   backbone               backbone
  (desoxirribose           (desoxirribose
   + fosfato)               + fosfato)
```

### Componentes do DNA

#### 1. Nucleotídeos (monômeros)

Cada nucleotídeo é composto por:

```
┌─────────────────────────┐
│                         │
│   Fosfato (PO₄³⁻)      │
│        │                │
│   Desoxirribose (açúcar)│
│        │                │
│   Base Nitrogenada      │
│   (A, T, C ou G)        │
│                         │
└─────────────────────────┘
```

#### 2. Bases Nitrogenadas

| Base | Tipo | Pareia com |
|------|------|------------|
| **Adenina (A)** | Purina | Timina (T) |
| **Timina (T)** | Pirimidina | Adenina (A) |
| **Guanina (G)** | Purina | Citosina (C) |
| **Citosina (C)** | Pirimidina | Guanina (G) |

> **Regra de Chargaff**: A = T e G = C (bases complementares)

#### 3. Ligações

- **Ligação fosfodiéster**: liga nucleotídeos na mesma fita
- **Pontes de hidrogênio**: ligam bases complementares entre fitas
  - A ═══ T (2 pontes de hidrogênio)
  - G ≡≡≡ C (3 pontes de hidrogênio)

### Direcionalidade do DNA

```
5' ─────→ 3'   (fita molde / sentido)
3' ←───── 5'   (fita complementar)
```

- **Extremidade 5'**: possui fosfato livre
- **Extremidade 3'**: possui hidroxila (-OH) livre

### Genes

- **Gene**: segmento de DNA que contém instruções para produzir uma proteína
- Humanos possuem cerca de **20.000-25.000 genes**
- Nem todo o DNA codifica proteínas (aproximadamente 1,5% são genes)

## 4. Estrutura do RNA

### O que é RNA?

**RNA** = Ácido Ribonucleico
É a molécula que **transporta a informação** do DNA para os ribossomos.

### DNA vs RNA

| Característica | DNA | RNA |
|----------------|-----|-----|
| Açúcar | Desoxirribose | Ribose |
| Bases | A, T, G, C | A, U, G, C |
| Estrutura | Dupla fita | Única fita |
| Localização | Núcleo | Núcleo + Citoplasma |
| Função | Armazenar info | Transportar info |

> **Diferença chave**: No RNA, a **Uracila (U)** substitui a Timina (T).

### Tipos de RNA

#### 1. RNA Mensageiro (mRNA)
- Transporta a informação do DNA para o ribossomo
- É a "cópia" de um gene
- É traduzido em proteína

```
DNA:    3'─TAC─GCA─AAT─CGG─5'
              ↓ Transcrição
mRNA:   5'─AUG─CGU─UUA─GCC─3'
```

#### 2. RNA Transportador (tRNA)
- Transporta aminoácidos para o ribossomo
- Possui um **anticódon** que reconhece o códon do mRNA

```
        Aminoácido
            │
    ┌───────┴───────┐
    │    tRNA       │
    │               │
    │  Anticódon    │
    └───────┬───────┘
            │
      Reconhece o códon
```

#### 3. RNA Ribossomal (rRNA)
- Componente dos ribossomos
- Atua como catalisador da síntese proteica (ribozima)

## 5. Replicação do DNA

### O que é Replicação?

Processo pelo qual o DNA faz uma **cópia idêntica** de si mesmo.
Ocorre antes da divisão celular.

### Passos da Replicação

```
1. DESEMPACOTAMENTO
   DNA helicase quebra as pontes de hidrogênio

   ════════════════════
   ════════════════════
        ↓
   ═══╗     ╔═══
   ═══╝     ╚═══

2. SÍNTESE
   DNA polimerase adiciona nucleotídeos complementares

   ═══╗     ╔═══
      ║     ║
   ═══╝═════╚═══

3. DUPLA HÉLICE
   Duas moléculas idênticas

   ════════════════════
   ════════════════════
   ════════════════════
   ════════════════════
```

### Enzimas Envolvidas

| Enzima | Função |
|--------|--------|
| **Helicase** | Desfaz a dupla hélice |
| **Topoisomerase** | Alivia a tensão da hélice |
| **Primase** | Cria um primer de RNA |
| **DNA Polimerase** | Adiciona nucleotídeos complementares |
| **Ligase** | Liga os fragmentos de Okazaki |

### Características

- **Semiconservativa**: cada molécula nova tem uma fita original + uma nova
- **Bidirecional**: começa em um ponto e vai nas duas direções
- **Sempre 5' → 3'**: a síntese só ocorre neste sentido

## 6. Transcrição (DNA → RNA)

### O que é Transcrição?

Processo em que a informação de um gene do DNA é **copiada** para um RNA mensageiro (mRNA).

```
LOCALIZAÇÃO: Núcleo celular

DNA:     3'─TAC─GCA─AAT─CGG─5'  (fita molde)
              ↓ Transcrição
mRNA:    5'─AUG─CGU─UUA─GCC─3'
```

### Passos da Transcrição

#### 1. Iniciação
- A **RNA Polimerase** se liga ao **promotor** (região inicial do gene)
- A dupla hélice se abre

```
     Promotor
        ↓
═══╗═════════════════════════════
   ║  RNA Polimerase se liga aqui
═══╝═════════════════════════════
```

#### 2. Elongação
- A RNA Polimerase percorre a fita molde (3' → 5')
- Monta o mRNA complementar (5' → 3')
- Bases complementares:
  - DNA **A** → RNA **U** (uracila)
  - DNA **T** → RNA **A**
  - DNA **G** → RNA **C**
  - DNA **C** → RNA **G**

```
Fita molde DNA:  3'─TAC─GCA─AAT─CGG─5'
                     ↓   ↓   ↓   ↓
mRNA formado:    5'─AUG─CGU─UUA─GCC─3'
```

#### 3. Terminação
- A RNA Polimerase encontra um **sinal de terminação**
- O mRNA é liberado
- O DNA sefecha novamente

### Processamento do mRNA (em eucariotos)

```
mRNA primário (pré-mRNA):
5'─exon─intron─exon─intron─exon─3'
          ↓ Splicing
mRNA maduro:
5'─exon──────exon──────exon─3'
```

- **Splicing**: remoção dos **íntrons** (sequências não codificadoras)
- **Exons**: sequências que ficam no mRNA final
- Adição da **cap** (5') e **cauda de poli-A** (3')

## 7. Tradução (RNA → Proteína)

### O que é Tradução?

Processo em que o mRNA é **interpretado** pelos ribossomos para produzir uma **proteína**.

```
LOCALIZAÇÃO: Ribossomos (citoplasma)

mRNA:    5'─AUG─CGU─UUA─GCC─3'
              ↓   ↓   ↓   ↓
Proteína:   Met─Arg─Leu─Ala
```

### Componentes da Tradução

| Componente | Função |
|------------|--------|
| **mRNA** | Fornece a mensagem (códons) |
| **tRNA** | Transporta aminoácidos |
| **Ribossomo** | Máquina de síntese proteica |
| **Aminoácidos** | Blocos de construção das proteínas |

### Ribossomo

```
     ┌───────────────────┐
     │   Subunidade      │
     │   Grande (60S)    │
     │                   │
     │  ┌─────────────┐  │
     │  │   Sítio P    │  │  ← Peptidil-tRNA
     │  ├─────────────┤  │
     │  │   Sítio A    │  │  ← Aminoacil-tRNA
     │  ├─────────────┤  │
     │  │   Sítio E    │  │  ← Saída
     │  └─────────────┘  │
     │   Subunidade      │
     │   Pequena (40S)   │
     └───────────────────┘
```

### Passos da Tradução

#### 1. Iniciação
- A subunidade pequena se liga ao mRNA
- O tRNA iniciador (Met) se liga ao **código de início (AUG)**
- A subunidade grande se junta

```
         AUG─CGU─UUA─GCC
          ↑
     tRNA iniciador
     (携带 Metionina)
```

#### 2. Elongação
- Cada **códon** do mRNA é lido
- O tRNA com o **anticódon** complementar se liga
- O aminoácido é adicionado à cadeia
- O ribossomo avança um códon

```
Códon:    AUG    CGU    UUA    GCC
           ↓      ↓      ↓      ↓
Aminoácido: Met → Arg → Leu → Ala
```

#### 3. Terminação
- O ribossomo encontra um **código de parada** (UAA, UAG ou UGA)
- A proteína é liberada
- O ribossomo se dissocia

### Resumo da Tradução

```
mRNA:  5'─AUG─GCU─UAC─AAA─UGA─3'
          │    │    │    │    │
         Met  Ala  Tyr  Lys  STOP
          │    │    │    │
          └────┴────┴────┘
              PROTEÍNA
```

## 8. O Código Genético

### Codons

- **Códon**: grupo de 3 nucleotídeos do mRNA
- Cada códon codifica **um aminoácido**
- Existem **64 códons** possíveis (4³ = 64)

### Tabela do Código Genético

| Códon | Aminoácido | Códon | Aminoácido |
|-------|------------|-------|------------|
| **AUG** | **Início (Met)** | UAA | STOP |
| UUU | Fenilalanina | UAG | STOP |
| UUC | Fenilalanina | UGA | STOP |
| UUA | Leucina | GCU | Alanina |
| UUG | Leucina | GCC | Alanina |
| CUU | Leucina | GCA | Alanina |
| CUC | Leucina | GCG | Alanina |
| AUU | Isoleucina | GGU | Glicina |
| AUC | Isoleucina | GGC | Glicina |
| AUA | Isoleucina | GGA | Glicina |
| GUU | Valina | GGG | Glicina |
| GUC | Valina | UCU | Serina |
| GUA | Valina | UCC | Serina |
| GUG | Valina | UCA | Serina |
| UCU | Serina | UCG | Serina |
| CCU | Prolina | CGU | Arginina |
| CCC | Prolina | CGC | Arginina |
| CCA | Prolina | CGA | Arginina |
| CCG | Prolina | CGG | Arginina |
| ACU | Treonina | AGU | Serina |
| ACC | Treonina | AGC | Serina |
| ACA | Treonina | AGA | Arginina |
| ACG | Treonina | AGG | Arginina |
| CAU | Histidina | GAA | Ácido glutâmico |
| CAC | Histidina | GAG | Ácido glutâmico |
| CAA | Glutamina | GAU | Ácido aspártico |
| CAG | Glutamina | GAC | Ácido aspártico |
| AAU | Asparagina | UAU | Tirosina |
| AAC | Asparagina | UAC | Tirosina |
| AAA | Lisina | UGU | Cisteína |
| AAG | Lisina | UGC | Cisteína |
| AUG | Metionina (Início) | UGG | Triptofano |

### Propriedades do Código

| Propriedade | Significado |
|-------------|-------------|
| **Degenerado** | Vários códons → mesmo aminoácido |
| **Universal** | Mesmo código em quase todos os seres vivos |
| **Não sobreposto** | Cada nucleotídeo pertence a um só códon |
| **Unívoco** | Cada códon → apenas um aminoácido |

### Exemplo de Leitura

```
Sequência: 5'─AUG GCU UAC AAA UGA─3'

Leitura:
  AUG = Met (Início)
  GCU = Ala
  UAC = Tyr
  AAA = Lys
  UGA = STOP

Proteína: Met─Ala─Tyr─Lys
```

> **Importante**: A leitura começa no AUG e para em um STOP. Mudar um nucleotídeo pode alterar todo o resultado!

## 9. Regulação Gênica

### Por que Regular Genes?

Nem todos os genes precisam estar ativos o tempo todo.
- Célula do fígado ≠ célula do cérebro
- Mesmo DNA, mas **genes diferentes expressos**

### Níveis de Regulação

```
1. TRANSCRICIONAL (mais importante)
   ┌─────────────────────────────┐
   │  DNA ──?──→ mRNA            │
   │  (ativador/repressor)       │
   └─────────────────────────────┘

2. PÓS-TRANSCRICIONAL
   ┌─────────────────────────────┐
   │  mRNA → processamento       │
   │  (splicing alternativo)     │
   └─────────────────────────────┘

3. TRADUCIONAL
   ┌─────────────────────────────┐
   │  mRNA ──?──→ proteína       │
   │  (acesso ao ribossomo)      │
   └─────────────────────────────┘

4. PÓS-TRADUCIONAL
   ┌─────────────────────────────┐
   │  Proteína → modificação     │
   │  (fosforilação, clivagem)   │
   └─────────────────────────────┘
```

### Operon (Procariontes)

O **operon lac** é um exemplo clássico:

```
SEM LACTOSE:                 COM LACTOSE:
                            
Promotor─Operador─genes      Promotor─Operador─genes
   │         │                   │         │
Repressor   BLOQUEADO         Indutor    LIBERADO
ligado ao   (sem transcrição) liga ao    (transcrição
operador                     repressor   occurs)
```

### Fatores de Transcrição

- **Promotor**: região onde a RNA Polimerase se liga
- **Enhancers**: sequências que aumentam a transcrição
- **Silencers**: sequências que diminuem a transcrição
- **Activators**: proteínas que ativam a transcrição
- **Repressors**: proteínas que bloqueiam a transcrição

## 10. Mutações

### O que é uma Mutação?

**Mutação** = alteração na sequência de nucleotídeos do DNA.

### Tipos de Mutações

#### 1. Mutações Gênicas (pontuais)

| Tipo | Exemplo | Consequência |
|------|---------|--------------|
| **Substituição** | AAA → AAG | Pode não alterar o aminoácido |
| **Inserção** | +1 nucleotídeo | Frameshift (muda tudo) |
| **Deleção** | -1 nucleotídeo | Frameshift (muda tudo) |

**Exemplo de Frameshift:**
```
Normal:    AUG GCU UAC AAA UGA
           Met Ala Tyr Lys STOP

Inserção:  AUG GCG CUU ACA AAU GA
           Met Ala Leu Thr Asn ... (diferente!)

Deleção:   AUG CUU ACA AAU GA...
           Met Leu Thr Asn ... (diferente!)
```

#### 2. Mutações Cromossômicas

| Tipo | Descrição |
|------|-----------|
| **Duplicação** | Segmento se repete |
| **Deleção** | Segmento é perdido |
| **Inversão** | Segmento inverte a direção |
| **Translocação** | Segmento troca de cromossomo |

#### 3. Mutações Genômicas

| Tipo | Descrição |
|------|-----------|
| **Aneuploidia** | Número irregular de cromossomos (ex: Síndrome de Down) |
| **Poliploidia** | Conjuntos extras de cromossomos |

### Causas de Mutações

| Causa | Exemplo |
|-------|---------|
| **Espontâneas** | Erros na replicação do DNA |
| **Físicas** | Radiação UV, raios X |
| **Químicas** | Substâncias mutagênicas |
| **Biológicas** | Vírus |

### Consequências

| Efeito | Descrição |
|--------|-----------|
| **Neutro** | Não altera a proteína |
| **Benéfico** | Melhora a adaptação |
| **Danoso** | Causa doença |
| **Letais** | Morte do organismo |

## 11. Resumo Geral

### Fluxo Central da Biologia Molecular

```
╔═══════════════════════════════════════════════════════════╗
║                                                           ║
║   DNA ──[Transcrição]──→ mRNA ──[Tradução]──→ Proteína  ║
║                                                           ║
║   Núcleo         Núcleo           Ribossomo              ║
║                  (splicing)       (citoplasma)            ║
║                                                           ║
╚═══════════════════════════════════════════════════════════╝
```

### Tabela de Comparação

| Etapa | O que acontece | Onde | Enzima principal |
|-------|----------------|------|------------------|
| **Replicação** | DNA → DNA (cópia) | Núcleo | DNA Polimerase |
| **Transcrição** | DNA → mRNA | Núcleo | RNA Polimerase |
| **Tradução** | mRNA → Proteína | Ribossomo | Ribossomo |

### DNA vs RNA (Resumo)

| Característica | DNA | RNA |
|----------------|-----|-----|
| Açúcar | Desoxirribose | Ribose |
| Bases | A, T, G, C | A, U, G, C |
| Fitas | 2 (dupla hélice) | 1 (única fita) |
| Localização | Núcleo | Núcleo + Citoplasma |
| Função | Armazenar info | Transportar info |
| Tamanho | Grande | Pequeno |

### O Caminho da Informação

```
GENE (DNA)
    ↓
    │ O gene contém a RECEITA
    ↓
mRNA
    ↓
    │ O mRNA é a CÓPIA da receita
    ↓
PROTEÍNA
    ↓
    │ A proteína é o PRODUTO final
    ↓
CARACTERÍSTICA DO INDIVÍDUO
```

## 12. Exercícios

### Exercício 1: Complementaridade

Se a fita molde do DNA é: **3'─TAC GCA AAT CGG 5'**

a) Qual é a sequência do mRNA transcrito?
b) Quais aminoácidos são codificados?

<details>
<summary>Resposta</summary>

a) mRNA: **5'─AUG CGU UUA GCC 3'**

b) Met - Arg - Leu - Ala

</details>

---

### Exercício 2: Tabela do Código Genético

Determine os aminoácidos para:

a) **5'─AUG UUU GAA 3'**
b) **5'─UAC AAA GGU 3'**

<details>
<summary>Resposta</summary>

a) Met - Phe - Glu

b) Tyr - Lys - Gly

</details>

---

### Exercício 3: Mutação

A sequência normal é: **5'─AUG GCU UAC AAA UGA 3'**

Se houver uma mutação que troca o 4º nucleotídeo (G→A):

**5'─AUG ACU UAC AAA UGA 3'**

a) Quantos aminoácidos diferentes resulting?
b) A proteína ainda é funcional?

<details>
<summary>Resposta</summary>

a) Met - Thr - Tyr - Lys (antes era Met - Ala - Tyr - Lys)

b) Pode não ser funcional, pois um aminoácido foi trocado (Ala → Thr)

</details>

( ) A tradução ocorre no núcleo.

( ) A DNA Polimerase sintetiza RNA.
( ) Íntrons são removidos durante o splicing.

<details>
<summary>Resposta</summary>

(×) Falso - O RNA possui Uracila, não Timina.
(×) Falso - A tradução ocorre nos ribossomos (citoplasma).

(×) Falso - A DNA Polimerase sintetiza DNA.
